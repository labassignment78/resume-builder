    Idea

    30-Day Seekhne ka Plan

    Roz sirf 1 ghanta — mahine ke aakhir me tumhare paas GitHub par dikhane layak kaam hoga.

    Week 1: HTML basics — headings, links, photos, lists. Week 2: CSS — rang, design, mobile layout. Week 3: JavaScript — buttons, click par kaam, chhoti game. Week 4: Apna project — resume page ya shop page bana kar GitHub + reel.

    GitHub par stars kaise aate hain?

    Sach ye hai: viral hone ki guarantee koi nahi de sakta. Lekin jin repos ko stars milte hain, un sab me ye cheezein common hoti hain — logon ka asli masla hal karna, pehli nazar me samajh aana, aur ek zabardast demo.

    Step 1

    Asli masla hal karo

    REA is liye famous hua ke usne developers ka mushkil kaam asaan kiya. Tumhara resume builder students ka masla hal karta hai, aur Roman Urdu tutorials un students ka jo English me atakte hain. Masla jitna asli, log utne zyada.

    Step 2

    README = tumhari dukaan

    Repo kholte hi pehli screen README hoti hai: pehli line me batao ye kya karta hai, ek screenshot ya GIF lagao, aur "kaise use karein" 3 steps me likho. Bina README wala repo log foran band kar dete hain.

    Step 3

    Demo reel banao

    30 second ki reel: "Pehle mera resume ✗ — ab dekho ✓". Screen recording, tez music, aur aakhir me GitHub link comment me pin karo. Ek reel, aur wohi content TikTok + YouTube Shorts par bhi.

    Step 4

    Roz thora, roz share

    "Day 1, Day 2…" series log follow karte hain. Seekhte hue banana sab se tez trust banata hai — log tumhare safar ke saathi ban jate hain, sirf ek repo ke visitor nahi.

    Step 5

    Logon ki madad maango — sahi tareeqe se

    Friends aur class fellows ko bolo: "Star de do aur batao kya kami hai?" Feedback se repo behtar hota hai, aur har star naye logon ko dikhata hai. Fake stars ya bots — kabhi nahi, GitHub pakar leta hai.

    Tumhara plan

    Do repo, ek loop

    Repo 1: ye Resume Builder (HTML file GitHub par). Repo 2: coding-seekho-roman-urdu (har lesson ek file). Reel resume builder ki banao, description me dono repos ke links — traffic ek doosre ko milega.

    Ek zaroori baat: Stars waqt lete hain — pehle hafte me 5 star bhi mil jayein to wo jeet hai. Asli jeet wo skill hai jo tum seekh jaoge; stars uske peeche khud aate hain.
    Resume Builder — students ke liye free toolkit. Details sirf tumhare browser me rehti hain; page band karne par kuch save nahi hota. Apni real maloomat hamesha sach likho — jhooti degree ya experience interview me pakri jati hai.
