# Resume Builder — Free, for Students

Ek free tool jisse koi bhi student apna professional resume bana sakta hai — form bharo, live preview dekho, aur PDF ya PNG me download karo.

## Kya kya hai

- **Resume Builder** — 3 templates (Modern, Classic, Bold Sidebar), 5 rang, Education/Experience add/remove, PDF aur PNG download, live ATS score Roman Urdu tips ke saath, 1-click Cover Letter generator aur WhatsApp job-application message generator.
- **Coding Seekho** — 8 Roman Urdu lessons (HTML, CSS, JavaScript, Python) jin me code badal kar live result dekhne wala "Try karo" box hai, plus 6 sawalon ka quiz.
- **Student Tools** — Skill-se-Paise Calculator, Username Generator, Urdu-script se Roman Urdu Typing Helper, HTML/CSS cheat sheets, 30-day seekhne ka plan.
- **GitHub Viral Guide** — stars lane ke 5 practical steps.

## Kaise use karein

`index.html` ko browser me kholo — koi install nahi chahiye. Ya GitHub Pages par host karke link share karo.

## Kaise bana hai

Sirf HTML, CSS aur JavaScript — koi server nahi, koi database nahi. Tumhara data tumhare browser me hi rehta hai, kahin save ya bheja nahi jata.
